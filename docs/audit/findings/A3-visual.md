# A3 · Visual & readability

Scope: findings of audit A3 (PLAN.md): screenshot sweep in both themes at 1280×800, 1440×900 and 2560×1440; token audit; WCAG AA contrast; loading/empty/error states; icons (UI-15); motion (UI-16); ADR-0023 literal signals; readability of numbers, tables, charts and viewer overlays.
Read when: triaging A3 or planning the visual / states fix batch.
Depends: audit/PLAN.md, A1-navigation.md (not repeated here), UI_SHELL (UI-*), VIEWER (VW-*), ADR-0010, ADR-0023, DASHBOARD (DB-*).

Run 2026-09-25 on `version_3-dev` @ `b388447` (uncommitted docs only), dev servers API :8040 / Vite :5200, fresh scratch workspace. State set up through the API: project "Dataset900 audit" (ccrcc pack, `.fixtures/synthetic/Dataset900`), completed PyRadiomics run "NP tumor" (33 items), two label tables, 3 curation events, a view-only token, plus an empty project for first-run states. Headless Chromium (Playwright from `frontend/node_modules`), DPR 1, theme set through `rw.settings`. Contrast = WCAG 2.x ratio from computed styles, with ancestor opacity and backgrounds composited (script in scratch). Browser locale = the machine default (comma decimal) unless stated.

## Works well (keep)

Contrast is almost clean: 16 page × theme sweeps (home, overview, case, dashboard, radiomics, labeling, queue, settings) found only the 4 near-misses in AUD-A3-19; muted text passes on every surface except `--btn-secondary` · ADR-0023's four decisions have shipped: labels in sentence case (no `uppercase`/`letter-spacing` anywhere in CSS), plane chip in the viewport header, slice index as "25 · 48" in the UI font, desaturated plane colours · the crosshair lines use the Slicer colours (axial red, sagittal yellow, coronal green) · viewports stay black in both themes, and the corner text (W/L, orientation letters) is 5.6:1 · GitHub Light is complete: no screen is missing light tokens · the status bar readout has units ("RAS 22.9, 24.5, 36 mm · HU 35") · `--dur-*` tokens drop to 0 under `prefers-reduced-motion` · the "Project not found" card shows its cause and a "Workspace home" button (the pattern UI-18 asks for) · the converter dry run shows clear stat cards · Project settings keeps a readable width even at 2560 px.
