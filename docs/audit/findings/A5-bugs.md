# A5 · Functional consistency & bugs

Scope: findings of audit A5 (PLAN.md): cross-feature consistency (effective phase, curation rollup, segmentation set, `lbl.*` / derived variables), concurrency and state (SSE, `If-Match`, archive/cancel/resume, two tabs), safety boundaries (view-only, path guards, R1/NFR-11, OPS-12, NFR-17 / PHI), targeted review of the high-risk modules; A1-19 and A6-02 hand-offs.
Read when: triaging A5 or planning a correctness / safety fix batch.
Depends: audit/PLAN.md, A0..A4, A6 findings (not re-reported), PHASE (PHS-*), CURATION (CUR-*), LABELING (LBL-*), VARIABLES (VAR-*), PROJECT_FORMAT (PRJ-*), TASKS (TSK-*), NFR.

Run 2026-09-25/26 on `version_3-dev` @ `b388447` + the uncommitted A2-01 fix, dev servers API :8050 / Vite :5210, scratch workspace and derived root, `plugins/threshold` via `scripts/rw-runner.py`. Projects: "A5 audit" (Dataset900, ccrcc, 6-item NP tumour run, threshold set `thr`, one label table), "A5 second" (Dataset900), "A5 dicom" (converter dataset `_datasets/a5ds`, P900/P901). Drivers: curl + headless Chromium (Playwright from `frontend/node_modules`). Fixtures only; nothing written into `.fixtures`.

## Checked and fine

View-only prefix: no write route; the 65 write routes (`grep @router.post|put|patch|delete` over `api/v1/`) are all outside `/view/{token}` → 405/404 · path guards: `..`, symlinks out of a data or derived root (Open, save `dest_dir`, `fs/list`) → 403; task outputs must realpath inside `output_dir` · OPS-12 overlap check at startup and on relink · `If-Match`: missing 428, stale 412, `*` accepted · two concurrent `imports` commits → one 409 `job-conflict`; two concurrent starts of the same task → one 409, no ghost run · phase join (PHS-03) is consistent in Explorer, case header, Image view, `/cases?phase=`, `dataset.jsonl` (`phase: CMP, phase_source: manual`) and radiomics selection by phase · curation severity table identical backend ↔ frontend; case rollup joined at read time · a bundle anonymises `metadata.jsonl` / `items.jsonl` / `cases.jsonl` rows as PRJ-08 says (UIDs replaced) · API latency on the fixtures is ≤ 10 ms per call (`/cases` 49 cases 10 ms, `dataset-table` 2.6 ms); NFR-01..03 not measurable at fixture scale (10k Explorer not generated).
